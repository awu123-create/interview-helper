# Interview Prep

围绕真实经历开展面试准备、复盘或演练的 Agent Skill，并维护一份跨会话准备档案。

## 使用

让支持文件读写的 Agent 加载 [interview-prep](skills/interview-prep/SKILL.md)，再明确指定任务：

- **准备**：根据简历、项目经历和目标岗位，整理准备重点、表达要点与可能追问。
- **复盘**：对照真实面试问题和原回答，分析具体问题，给出改进建议。
- **演练**：连续模拟面试，根据回答追问，结束后集中反馈。

例如：

> 使用 interview-prep 做演练。围绕订单重试项目问一个主问题，再追问两次，回答完后集中反馈。档案使用我指定的 Markdown 文件。

首次使用时指定档案位置，后续沿用。档案放在 skill 目录之外；事实、用户补充、模型推断和未知项分开保存。准备或复盘完成后更新档案，演练结束并集中反馈后再更新。

## 人工验收

修改流程后，在实际宿主中加载 skill，用以下虚构材料试用。测试档案放在仓库外，使用明确的绝对路径；各场景使用独立文件。检查真实回复和文件内容，无法执行的场景记为未验证。

### 连续演练后集中反馈

输入：“演练，档案在 `<档案路径>`。我负责订单重试模块，总体方案由同事负责，没有可核验的收益数字。问一个主问题，再追问两次，第三次回答后结束。”

逐次回答，可使用“我负责重试逻辑，幂等键校验沿用了已有组件”“总体方案由同事决定”“这部分记不清，暂时不能确认”，不要补造事实。

预期：每次只呈现当前问题，并根据回答追问；第三答前不给点评或参考答案，不写入档案评价。第三答后集中反馈、保存并读回，不自动追加下一轮。

### 纠正事实并在新会话沿用

在测试档案中写入当前事实“主导总体架构”，历史问答“你负责什么？我主导了总体架构”，以及建议“准备架构主导权的案例”。输入：“准备，档案在 `<档案路径>`。纠正：我只负责重试模块，总体方案由同事负责，之前说错了。其余细节暂时不补充。”

预期：当前事实和相关建议得到修正，历史原答保留并另记纠正；准备完成后停止，不自动演练。随后在新会话中只提供 skill、同一档案路径和“继续准备个人职责表达”，确认 Agent 实际读取文件并沿用纠正后的内容。

### 无法保存时如实说明

先创建一份只记录“目标：准备项目方案取舍”的测试档案，确保下面的问答尚未记录。使用能读取该档案、但实际禁止文件写入的测试会话，输入：“复盘，档案在 `<档案路径>`。原问：你为什么选这个方案？原答：大家都这么做，我就用了。补充：我只参与评审，没做过方案对比。这是回忆，不是逐字记录。不要修改权限或换路径。”

预期：反馈关联原问原答并注明回忆性质；明确新增内容未保存，给出可复制增量，不自动演练。检查原档案未变。仅在提示中声称不可写，不能算验证了保存失败。
